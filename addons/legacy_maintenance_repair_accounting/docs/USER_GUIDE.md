# User Guide

## Repair Existing Machine

Create a Work Centre Maintenance Request, select Repair Existing Machine and the existing Equipment, then create/open its Repair Order. Add operations, labour, and Repair Parts. Create the Material Requisition, submit it for Finance classification, approve the requisition, reserve/receive stock, and complete the Repair issue. Process unused material with Return Material. Finish operations and labour approvals, post accounting, and complete the Repair Order.

## Build New Machine

Create a Build Work Centre request, set the machine name and target Work Centre on the linked Repair Order, then process operations, labour, materials, returns, and postings. Select Capitalize Build, review the material/labour CAPEX and accounts, set dates, and confirm. Odoo posts PPE/CWIP, creates or reuses Equipment, assigns the Work Centre, records commissioning and cost, and links an asset when available.

Use Maintenance Cost Reporting for cost summaries, material traceability, operation progress, CAPEX/OPEX, accounting reconciliation, and exceptions.
