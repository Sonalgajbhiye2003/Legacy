# Configuration Guide

Open Accounting > Configuration > Settings > Maintenance and Repair Accounting for each company.

Configure the CWIP, Repair Expense, PPE, Accumulated Depreciation, Inventory, and Labour Clearing accounts; Labour, Material, and Capitalization journals; CAPEX and OPEX production locations; labour posting mode; default labour rate; and zero-cost policy. Automated valuation requires the selected production locations and product categories to have valid stock valuation accounts. Cross-company accounts, journals, and locations are rejected.

If Enterprise Assets and the optional bridge are installed, select a Build Asset Model. Without it, capitalization and Equipment commissioning still work and a draft asset can be linked for Finance completion.
